This module is a currency rate provider for `Currency Rate Update <https://github.com/OCA/currency/tree/19.0/currency_rate_update>`_.

It will query the Central Bank of Venezuela (BCV) website to obtain rates for:

* US Dollar (USD)
* Euro (EUR)
* Chinese Yuan (CNY)
* Russian Ruble (RUB)
* Turkish Lira (TRY)
