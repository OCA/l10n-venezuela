===============================
Venezuela - Loyalty & Discounts
===============================

Localización venezolana de Coupons & Loyalty y dueña de los descuentos
globales SENIAT.

**Table of contents**

.. contents::
   :local:

Description
===========

Incluye descuentos globales en borrador y descuentos post-factura, y adapta
recompensas loyalty para no usar productos en documentos fiscales VE.

Installation
============

Al actualizar ``l10n_ve_seniat``, el pre-migrate instala este módulo
automáticamente.

=====
