Management Withholding VAT Venezuelan Laws
===========================================

This module allows managing VAT Withholding (Retención de IVA) according to Venezuelan SENIAT legislation:
- Automatic calculation of VAT withholding (75% or 100%).
- Generation and printing of official VAT Withholding Voucher (Comprobante de Retención de IVA).
- Generation of the monthly / bi-weekly TXT file for SENIAT declarative portal.
- Multi-currency and refund support.
