This connector coordinates customer advances with IGTF payments.

Advance applications do not create a new IGTF charge, and IGTF
overpayments post only their net surplus to the customer advance
account.

Use Cases / Context
===================

IGTF and customer advances both alter payment journal items and payment
differences. Their shared behavior belongs in an optional connector so
each base module remains independently installable.

Usage
=====

The module installs automatically when both Venezuela IGTF and Venezuela
Payment Advance are installed.

Use the standard payment registration and advance application flows. No
additional configuration is required.
