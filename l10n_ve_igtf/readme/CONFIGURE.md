1. Go to **Accounting > Configuration > Settings > Venezuela - IGTF**.
2. Set the default IGTF rate and the expense account.
3. For incoming perceptions, enable **IGTF Perception Agent**, set the effective
   date, and configure the perception liability account.
4. Open each foreign-currency or cryptoasset payment journal and enable
   **Enable IGTF**.

Enabling a journal only makes the option available. It does not classify every
transaction in that journal as taxable.
