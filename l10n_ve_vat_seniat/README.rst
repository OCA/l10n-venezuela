Adds SENIAT BuscaRif lookup buttons on Venezuelan contacts so users can
fetch taxpayer name, taxpayer type and withholding type from the
official portal.

Use Cases / Context
===================

Venezuelan contacts store a RIF that must match SENIAT records. Looking
up that data by hand on the BuscaRif portal is slow and error-prone.
This module queries the portal from the contact form and maps the result
to fiscal fields.

Installation
============

The server needs Tesseract OCR and the Python packages ``requests``,
``Pillow`` and ``pytesseract``.

On Debian or Ubuntu:

::

   apt install tesseract-ocr
   pip install requests Pillow pytesseract

Usage
=====

1. Install ``l10n_ve_vat_seniat``.
2. Open a Venezuelan contact with a RIF in the VAT field.
3. Use the refresh button next to the VAT field to query SENIAT.
4. Use the share button to open BuscaRif in a new browser tab.

A successful query updates the commercial partner name, taxpayer type
and withholding type when the portal data can be mapped.
