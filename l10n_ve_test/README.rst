Use Cases / Context
===================

The localization is split across many addons. This module exists so we
can detect inheritance and view conflicts after they are installed
together.

Not pulled here: l10n_ve_bank_reconcile_ref (OCA reconcile excludes
Invoicing in this stack), l10n_ve_reports and its dependents (reports
XML needs account.report actions that fail to load).

Usage
=====

1. Point --addons-path to this clone instead of the live l10n-venezuela
   tree.
2. Create an empty database.
3. Install l10n_ve_test (it pulls every l10n_ve\_\* addon).
4. Run: odoo --test-enable --stop-after-init --test-tags=/l10n_ve_test
