Fiscal Report For Venezuela
===========================

This module generates official Venezuelan Fiscal Books:
- Purchase Fiscal Book (Libro de Compras) according to SENIAT regulations.
- Sale Fiscal Book (Libro de Ventas) according to SENIAT regulations.
- Aliquot classification (General, Reduced, Additional, Exempt, SDCF).
- Cross-referencing with VAT Withholding vouchers.
- Official printable QWeb reports.
