Fiscal Report For Venezuela
===========================

This module generates official Venezuelan Fiscal Books:
- Purchase Fiscal Book (Libro de Compras) according to SENIAT regulations.
- Sale Fiscal Book (Libro de Ventas) according to SENIAT regulations.
- Aliquot classification (General, Reduced, Additional, Exempt, SDCF).
- Cross-referencing with VAT Withholding vouchers.
- Official printable QWeb reports.

Configuration
=============

Ensure that all Taxes are properly tagged with their Venezuelan Aliquot Type (General, Reduced, Additional, Exempt).

Usage
=====

1. Go to Accounting > Venezuelan Localization > Fiscal Books.
2. Create a new fiscal book for a given month and type (Purchase or Sale).
3. Click 'Update Book' to automatically fetch and classify all posted invoices.
4. Print the official report via 'Print Fiscal Book'.
