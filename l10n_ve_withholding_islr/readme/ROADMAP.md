* Withholding territoriality is not inferred: a bill line is withheld only
  when it carries a concept, so the user decides which payments to
  non-residents are Venezuelan-source income.
* Gross-up (tax assumed by the payer) is not supported.
* Tarifa N° 2 vouchers of later months are not recomputed when an earlier
  bill of the same vendor changes; correct them manually if needed.
* Providencia Administrativa SNAT/2026/00093 sets a unified digital regime for
  withholding vouchers starting 19 April 2027; it is not implemented yet.
