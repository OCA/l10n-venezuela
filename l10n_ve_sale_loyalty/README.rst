Usage
=====

Instale l10n_ve_sale_loyalty cuando necesite descuentos globales SENIAT
en pedidos de venta. Requiere l10n_ve_seniat_sale y l10n_ve_loyalty.

Se instala automáticamente si ambos módulos están presentes.
