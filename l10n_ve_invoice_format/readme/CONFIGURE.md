In Accounting settings, configure the authorized printer name, RIF, SENIAT
resolution, and assigned control-number range for each Venezuelan company.

To show the bolivar equivalent on fiscal documents, select the reference
currency. The currency must have an exchange rate available for the document
date. Leave the field empty to omit this block.

Enable **Show Untaxed and Tax Amounts on Invoice Lines** to add both columns to
customer fiscal documents that contain taxes.
