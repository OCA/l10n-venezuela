This addon adapts the standard invoice report to Venezuelan
fiscal-document requirements. It adds the fiscal control number and
assignment date, marks exempt lines, formats the legal document date,
and prints authorized printer information.

Companies can also show document totals in a configured bolivar
reference currency using the exchange rate at the document date, and
show untaxed and tax amounts on each invoice line.

The report changes apply only to Venezuelan customer fiscal documents.
Other customer invoices and vendor documents keep the standard Odoo
report output.

The legal basis covered by this addon includes Providencia
Administrativa SNAT/2011/00071 and Providencia Administrativa
SNAT/2024/000102.

Configuration
=============

In Accounting settings, configure the authorized printer name, RIF,
SENIAT resolution, and assigned control-number range for each Venezuelan
company.

To show the bolivar equivalent on fiscal documents, select the reference
currency. The currency must have an exchange rate available for the
document date. Leave the field empty to omit this block.

Enable **Show Untaxed and Tax Amounts on Invoice Lines** to add both
columns to customer fiscal documents that contain taxes.

Usage
=====

Print a Venezuelan customer invoice with the standard Odoo invoice
report. The addon automatically adds the applicable legal information
and presentation details.

The fiscal control number and assignment date come from
``l10n_ve_fiscal_document``. Configure and assign those values using
that addon's document workflow.
